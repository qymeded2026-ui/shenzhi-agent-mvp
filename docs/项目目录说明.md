# 神志思训项目目录说明

## 根目录：主程序与核心模块

- `app.py`：网页主程序。
- `stability_store.py`：会话数据库、日志和备份。
- `stability_diagnostics.py`：系统自检和脱敏诊断包。
- `requirements.txt`：Python 依赖。

## 脚本目录

- `scripts/start_app.sh`：启动网页。
- `scripts/run_health_check.sh`：快速系统自检。
- `scripts/run_pre_demo_check.sh`：演示前完整自动检查。
- `scripts/run_regression_tests.sh`：自动化回归测试。
- `scripts/run_performance_benchmark.sh`：性能基准测试。
- `scripts/run_stress_acceptance.sh`：真实压力测试。
- `scripts/diagnostics_cli.py`：终端自检入口。

## 数据与资源目录

- `cases/`：234 例结构化脱敏病例。
- `tongue_images/`：234 张匿名化舌象及匿名化清单。
- `training_assets/`：第二阶段生成式训练样本与脚本。
- `assets/`：网页 Logo 和静态图片。

## 运行时目录

- `runtime/`：SQLite 会话数据库、运行日志和自动备份。
- `reports/`：自检报告与压力测试报告。

这两个目录属于本机运行产物，已加入 `.gitignore`，不应上传到 GitHub。

## 开发辅助目录

- `tests/`：回归、性能、自检和压力测试代码。
- `scripts/`：运行、验收和维护脚本。
- `docs/stability/`：历次稳定性补丁说明和人工验收清单。
