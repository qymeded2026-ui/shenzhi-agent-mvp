# 功能开发 2.1：个性化量表推荐

## 设计原则

系统不会把中医证型机械等同于某一种精神心理量表。右侧“量表评估”页签采用两层教学推荐：

1. 根据当前证型显示一项核心量表。
2. 根据当前病例的症状、风险等级和病例库历史参考分，必要时追加一项补充量表。

量表推荐仅用于教学训练，不用于真实临床诊断。

## 病例库核对结果

当前病例库共 `234` 例，覆盖 `7` 个证型。每例病例都保存了 `HAMD-24`、`HAMA` 和 `PHQ-9` 历史参考分。

| --- | ---: | ---: | ---: | --- |
| 肝郁脾虚证 | 87 | 25.4 | 19.9 | HAMD-17 |
| 心脾两虚证 | 36 | 24.2 | 20.3 | HAMD-17 |
| 肝气郁结证 | 34 | 19.1 | 16.7 | HAMA |
| 痰气郁结证 | 32 | 22.8 | 16.6 | HAMA |

## 核心量表规则

| 证型 | 核心量表 | 病例库中的教学线索 |
| --- | --- | --- |
| 肝郁脾虚证 | HAMD-17 | 低落、兴趣减退、乏力和食欲变化较常见 |
| 心脾两虚证 | HAMD-17 | 低落、兴趣减退、失眠和乏力较常见 |
| 心神失养证 | HAMD-17 | 低落、失眠和兴趣减退较常见 |
| 心肾阴虚证 | HAMD-17 | 样本较少，但低落、失眠和风险线索较集中 |
| 肝气郁结证 | HAMA | 焦虑、烦躁、失眠和胸闷等线索较常见 |
| 痰气郁结证 | HAMA | 焦虑、胸闷和咽部异物感等线索较常见 |
| 气郁化火证 | HAMA | 易激惹、烦躁和失眠等线索较常见 |

## 补充量表规则

核心量表为 `HAMD-17` 时，满足以下任一条件则追加 `HAMA`：

- 焦虑相关症状至少命中2项。
- 病例库历史 `HAMA >= 20`。

核心量表为 `HAMA` 时，满足以下任一条件则追加 `HAMD-17`：

- 抑郁相关症状至少命中2项。
- 病例库历史 `HAMD-24 >= 24`。
- 风险等级提示自伤自杀线索。

## 页面行为

- 选择或随机抽取病例后，右侧只显示当前病例推荐的量表。
- 推荐区标注“核心量表”或“补充量表”，并显示推荐原因。
- `HAMD-17` 使用17个条目逐项评分，系统自动计算总分。
- `HAMA` 使用14个条目逐项评分，系统自动计算总分。
- 病例库的 `HAMD-24` 历史参考分仅作为来源提示，不与本轮 `HAMD-17` 直接比较。
- 量表结果同步进入督导老师Agent、SOAP病历和下载的JSON训练记录。

## 全量审计结果

对 `234` 例病例逐例运行推荐规则后，没有发现漏配或重复量表：

| 页面实际显示 | 病例数 |
| --- | ---: |
| 仅显示 HAMD-17 | 23 |
| HAMD-17 为核心，HAMA 为补充 | 134 |
| 仅显示 HAMA | 15 |
| HAMA 为核心，HAMD-17 为补充 | 62 |

专项量表后续仍可扩展。例如：双相或躁狂线索可接入 `YMRS`，精神病性症状可接入相应专项量表。当前版本先聚焦病例库已有参考数据可支持的 `HAMD-17` 与 `HAMA`，避免把尚未结构化验证的量表直接混入训练评分。
