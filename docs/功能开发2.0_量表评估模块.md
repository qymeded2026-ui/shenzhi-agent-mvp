# 功能开发 2.0：量表评估模块

## 已实现内容

右侧教学辅助区新增“量表评估”页签，包含：

- `HAMD-17 教学评分`：学生依据问诊和观察逐项选择17个条目的分值，系统自动计算总分并提示问诊证据覆盖情况。
- `HAMA 教学评分`：学生依据问诊和观察逐项选择14个条目的分值，系统自动计算总分并提示问诊证据覆盖情况。

## 教学边界

- 量表记录与原有 `100分问诊评分` 相互独立。
- 病例库中的量表分数只作为教学复盘参考，不会自动冒充学生本轮施测结果。
- `HAMD-17` 和 `HAMA` 属于临床评定量表。系统不根据患者自然语言自动替学生打分，而是让学生根据问诊与观察完成教学评分。
- `HAMD-17` 的“自杀”条目不为0时，系统提醒继续补问自杀意念、具体计划、可及手段与保护因素。
- 病例库现存的是 `HAMD-24` 历史参考分。由于版本不同，系统只展示来源说明，不会将它与学生本轮的 `HAMD-17` 总分直接比较。
- `PHQ-9` 患者自评入口已移除，避免学生代替患者填写造成角色混淆。

## 与现有功能的联动

- 每个问诊会话独立保存量表状态。
- 切换病例时清空旧量表记录。
- 修改量表后，旧的训练提交状态和SOAP会自动失效，避免使用过期结果。
- 督导老师Agent可以读取当前量表状态。
- SOAP病历区分“本轮实际施测”和“病例库教学参考”。
- 下载的JSON训练记录包含量表原始记录和汇总结果。

## 沟通技巧评分优化

沟通技巧由原来的3项扩充为6项：

- 共情回应
- 鼓励表达
- 开放式提问
- 澄清追问
- 总结确认
- 尊重与非评判

学生使用自然表达进行共情、鼓励患者慢慢说、开放式追问或总结确认时，更容易得到对应维度的分数。
