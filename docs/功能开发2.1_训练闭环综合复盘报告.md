# 功能开发 2.1：训练闭环综合复盘报告

## 开发目标

在问诊结束后，系统自动生成一份教学用综合复盘报告，把一次训练串成完整闭环：

学生问诊 → 患者 Agent 回答 → 规则评分 → 量表评估 → SOAP 病历 → 病例库标准对照 → 综合教学反馈。

## 本次新增内容

1. 新增综合复盘报告生成器。
   - 不额外调用大模型，优先保证课堂演示稳定性。
   - 报告内容来自病例库、问诊记录、规则评分、量表记录和 SOAP 状态。

2. 新增会话级报告保存字段。
   - `review_report`
   - `review_report_generated_at`

3. 新增报告下载。
   - 支持导出 Markdown 文件。
   - 继续保留 JSON 原始训练记录下载。

4. 报告自动失效机制。
   - 新增问诊后清空旧报告。
   - 切换病例后清空旧报告。
   - 修改量表评分后清空旧报告。
   - 重新生成 SOAP 后清空旧报告，避免报告引用过期 SOAP 状态。

## 报告包含内容

- 病例库标准对照
- 总分与各维度评分
- 病例必问点覆盖情况
- 风险筛查复盘
- 中医四诊与辨证信息采集
- HAMD-17/HAMA 量表评估复盘
- SOAP 病历状态
- 下一步教学建议

## 使用方式

1. 完成多轮问诊。
2. 完成必要量表评分。
3. 点击“结束问诊”或右侧“训练提交”。
4. 在“训练复盘与 SOAP 病历”中点击“生成综合复盘报告”。
5. 可直接查看报告，也可下载 Markdown 文件。
