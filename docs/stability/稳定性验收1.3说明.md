# 稳定性验收 1.3：真实压力测试

## 目标

在不调用 DeepSeek API、不修改真实问诊记录的前提下，对当前 MVP 做一轮可重复执行的本机压力测试。

## 运行方式

在终端执行：

```bash
cd /Users/qymeded/Desktop/shenzhi_agent_mvp
./scripts/run_stress_acceptance.sh
```

脚本会自动创建临时 SQLite 数据库，完成测试后自动删除临时数据，并在项目内的 `reports/` 文件夹生成 Markdown 和 JSON 两份验收报告。

## 自动覆盖场景

- 150 个问诊会话、每个 30 轮的批量保存与恢复。
- 10 个并发线程共 600 次 SQLite 写入。
- 180 次快速病例切换。
- 30 轮长问诊页面渲染与更早记录分页。
- 50 个近期会话的侧栏恢复与渲染。
- 20 轮连续患者问诊提交与页面重跑。
- 模型失败后保留待重试问题，并在恢复后重新生成患者回答。

## 结果说明

终端显示 `自动压力测试：7/7 场景通过` 时，说明本机自动验收通过。

`reports/` 已加入 `.gitignore`，因此本地验收报告不会被误上传到 GitHub。

## 边界

这套测试适用于当前单机 Streamlit MVP。它可以验证本地数据库、页面重跑、长会话和模型失败恢复，但不能替代正式服务器环境中的多人并发、网络层和部署压力测试。
