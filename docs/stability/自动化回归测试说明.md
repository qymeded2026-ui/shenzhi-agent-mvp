# 神志思训自动化回归测试

## 运行方式

在终端中执行：

```bash
cd "/Users/qymeded/Desktop/shenzhi_agent_mvp"
./scripts/run_regression_tests.sh
```

也可以直接运行：

```bash
.venv/bin/python -m unittest discover -s tests -p "test_*.py" -v
```

## 测试范围

当前自动化测试覆盖：

1. 首页打开时不会自动调用模型或生成 SOAP。
2. 学生问诊成功后，患者回答会写入 SQLite。
3. 患者回答生成失败时，错误不会写入问诊记录，并可重新生成。
4. 督导老师调用失败时，会回退到规则版教学提示。
5. 未提交训练时，点击 SOAP 按钮不会调用模型。
6. 页面中断前未完成的患者请求，可恢复为重新生成状态。
7. 20 轮长对话恢复后，默认只渲染最近 16 轮，并支持加载更早记录。
8. SQLite 会话保存、恢复和删除正常。
9. 精神病性症状筛查问题会正确增加鉴别诊断意识评分。
10. SQLite 内容没有变化时，不会重复写入。
11. 30 轮长对话恢复后，仍只渲染最近 16 轮。

## 注意事项

- 测试使用临时数据库，不会修改真实的 `runtime/shenzhi_sessions.db`。
- 测试使用本地模型桩，不会消耗 DeepSeek API 额度。
- 运行结束后看到 `OK`，说明全部自动化测试通过。
