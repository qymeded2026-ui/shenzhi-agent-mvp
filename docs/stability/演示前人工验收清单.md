# 神志思训演示前人工验收清单

## 一、自动检查

在终端执行：

```bash
cd /Users/qymeded/Desktop/shenzhi_agent_mvp
./scripts/run_pre_demo_check.sh
```

确认终端中没有 `FAIL`，并看到压力测试 `7/7` 场景通过。

## 二、页面基本检查

- [ ] 打开网页后，左侧栏可以正常显示。
- [ ] 展开左侧栏 `系统自检`，确认没有“异常”项目。
- [ ] 点击“生成脱敏诊断包”，确认可以下载 ZIP 文件。
- [ ] 新建问诊、重命名问诊、切换问诊和删除问诊均可使用。

## 三、长问诊与页面滚动

- [ ] 连续问诊 30 轮。
- [ ] 页面可以顺滑向上查看历史记录。
- [ ] 桌面端页面滚动时，学生问诊输入栏以深色胶囊形态固定悬浮在视口底部，不随页面离开屏幕。
- [ ] 悬浮胶囊宽度比问诊区略窄，整体与问诊区居中对齐，输入文字和按钮垂直居中。
- [ ] 点击悬浮胶囊左侧 `+`，可以选择病例或随机抽取病例；点击右侧 `结束问诊` 会按提交标准判断。
- [ ] 桌面端页面滚动时，右侧 `AI 教学辅助` 整块面板固定在视口右侧，不随页面离开屏幕。
- [ ] 缩窄浏览器窗口后，输入栏和右侧教学辅助区恢复流式布局，没有遮挡问诊内容。
- [ ] 点击“加载更早记录”，确认较早对话可以显示。
- [ ] 舌象提问后，确认当前病例舌象图片可以显示。

## 四、病例切换

- [ ] 连续切换 20 个病例。
- [ ] 每次切换后病例名称、训练目标和舌象图片对应正确。
- [ ] 刷新浏览器后，确认近期问诊记录和当前病例可以恢复。

## 五、模型故障恢复

- [ ] 暂时断开网络后提交一次问诊。
- [ ] 确认页面提示可以重新生成患者回答，错误文本没有写入正式问诊记录。
- [ ] 恢复网络并点击“重新生成患者回答”。
- [ ] 确认问诊可以继续。

## 六、督导老师与提交

- [ ] 连续向督导老师提问 10 次。
- [ ] 确认历史反馈可以左右翻页。
- [ ] 展开评分详情，确认风险筛查和精神病性症状命中正确维度。
- [ ] 提交训练，生成 SOAP 病历并下载 JSON 记录。

## 七、双标签页

- [ ] 同时打开两个浏览器标签页。
- [ ] 分别完成一次问诊和刷新。
- [ ] 再次执行 `./scripts/run_health_check.sh`，确认数据库检查正常。
