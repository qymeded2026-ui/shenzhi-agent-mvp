# 神志思训性能补丁 1.2

## 本次优化

1. SQLite 只更新真正变化的会话内容。
2. 页面状态没有变化时，跳过重复数据库连接和写入。
3. 规则评分结果加入缓存，避免展开折叠区或切换标签时重复计算。
4. 训练完成度加入缓存。
5. 舌象图片路径缓存 60 秒，减少重复扫描文件夹。
6. 左侧“近期问诊”搜索使用 `st.fragment`，搜索时只刷新侧栏列表。
7. 继续保留长对话分页：默认只渲染最近 16 轮。
8. 增加性能回归测试，验证无变化写入跳过和 30 轮会话分页渲染。
