# 稳定性补丁 1.4：故障自检与人工验收

## 本次增加的能力

### 1. 启动自检

网页首次打开时会自动检查：

- `cases/` 中是否有 234 例可解析 JSON 病例。
- `tongue_images/` 中是否有 234 张匿名化舌象，病例引用是否完整。
- `runtime/` 是否可写、磁盘空间是否充足。
- SQLite 会话数据库是否可以通过 `PRAGMA quick_check`。
- DeepSeek API Key 或本地测试模型桩是否已配置。
- Streamlit、Requests、OpenAI Python 依赖是否安装。

页面左侧栏新增折叠区域：`系统自检`。

### 2. 数据库自动备份

- 网页启动时自动检查是否需要备份。
- 最多每 6 小时新增一份 SQLite 快照。
- 默认保留最近 10 份备份。
- 备份位置：`runtime/backups/`。

### 3. 脱敏诊断包

页面左侧栏可以生成并下载诊断包。终端也可以执行：

```bash
./scripts/run_health_check.sh
```

诊断包仅包含：

- 系统自检报告。
- Streamlit 稳定性配置。
- 最近 300 行运行日志。
- API Key 是否已配置的脱敏状态。

诊断包不会包含病例 JSON、舌象原图、API Key 或原始问诊数据库。

### 4. 演示前自动检查

演示或外部试用前执行：

```bash
./scripts/run_pre_demo_check.sh
```

脚本会依次执行：

1. 系统自检与诊断包生成。
2. 自动化回归测试。
3. 稳定性验收 1.3 压力测试。

## 文件说明

- `stability_diagnostics.py`：自检与诊断包逻辑。
- `scripts/diagnostics_cli.py`：终端自检入口。
- `scripts/run_health_check.sh`：快速自检命令。
- `scripts/run_pre_demo_check.sh`：演示前自动验收命令。
- `tests/test_diagnostics.py`：自检、备份和脱敏诊断包回归测试。
