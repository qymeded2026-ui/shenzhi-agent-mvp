# 脚本目录

## 日常运行

```bash
./scripts/start_app.sh
```

## 演示前检查

```bash
./scripts/run_pre_demo_check.sh
```

## 单项维护

```bash
./scripts/run_health_check.sh
./scripts/run_regression_tests.sh
./scripts/run_performance_benchmark.sh
./scripts/run_stress_acceptance.sh
```

`diagnostics_cli.py` 是系统自检的 Python 命令行入口，通常无需单独运行。
